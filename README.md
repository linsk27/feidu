# feidu

Nuxt 3、Vue、Tailwind CSS 和 ECharts 智慧社区数据大屏，展示社区管理、安防监控、CIM 平台、能源检测和节能分析等可视化界面。

- 线上演示：https://feidu-murex.vercel.app
- 项目介绍：https://linsk27.github.io/projects/feidu/
- 作者主页：https://github.com/linsk27

![feidu smart community dashboard](./docs/feidu-smart-community-dashboard.jpg)

## 项目定位

feidu 不是单个图表练习，而是一个完整的大屏前端项目。它把社区人口概况、摄像头监控、报警信息、CIM 场景、舒适度数据、能耗概况、系统能效和机组运行状态组织在一个界面中，适合用于智慧社区、智慧园区、安防运维、能源监测和数据可视化作品展示。

## 功能模块

- 社区管理：社区总人数、业主人数、访客人数、外来人数等基础数据。
- 安防监控：摄像头预览、报警信息列表、报警状态与时间线。
- CIM 平台：城市 / 社区空间场景展示和楼宇点位标注。
- 能源检测：能耗、负荷、电费、室内舒适度等统计面板。
- 节能分析：系统能效、机组运行状态和趋势图表。
